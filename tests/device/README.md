# Testes Device-in-the-loop do Files

Os testes desta pasta validam o comportamento do Files em hardware real,
incluindo toggles, persistência NVS, estabilidade e power-cycle.

**Nunca execute estes testes automaticamente como agente de IA.** O comando
`--device` ou `--reboot` só deve ser usado após solicitação explícita do
usuário.
